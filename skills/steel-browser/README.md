# Steel Browser

Skill for browser automation with Steel cloud sessions and terminal-first browser commands.

## Source

- Skill source: <https://github.com/steel-dev/cli/tree/main/skills/steel-browser>
- CLI repo: <https://github.com/steel-dev/cli>
- Browser repo: <https://github.com/steel-dev/steel-browser>
- Docs: <https://docs.steel.dev/llms-full.txt>

## Install

```bash
npm i -g @steel-dev/cli
steel login
```

## What it covers

- Multi-step website automation with persistent sessions
- Web extraction and clean markdown scraping
- Screenshots and PDFs as artifacts
- CAPTCHA and anti-bot-sensitive flows

Use the `SKILL.md` file for the workflow and command patterns.
