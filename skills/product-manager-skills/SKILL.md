# Product Manager Skills

Senior PM agent skill for Claude Code. Covers 6 knowledge domains, 30+ strategic frameworks, 32 SaaS metrics with exact formulas, 12 stakeholder communication templates, and anti-pattern detection.

## Features

- **SaaS Metrics**: 32 metrics with exact formulas (MRR, ARR, NRR, LTV, CAC, Quick Ratio, Rule of 40, etc.)
- **Strategic Frameworks**: RICE, JTBD, Kano, Porter's Five Forces, Blue Ocean, Opportunity Solution Trees
- **Templates**: Executive updates, board prep, sprint reviews, launch briefs, QBRs, and more
- **Anti-Pattern Detection**: Identifies feature factory, HiPPO-driven roadmaps, metric theater, scope creep
- **Discovery**: Customer development interviews, assumption mapping, design sprints
- **Career Coaching**: PM career transitions and growth paths
